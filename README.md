# 声息 · SoundBreathe

专为深夜失眠、独处放松与专注打造的移动端环境音混音与 4-7-8 呼吸疗愈 H5。

- **公网访问**：https://vuxiao.github.io/soundbreathe/
- **纯前端零外链**：基于原生 `Web Audio API` 实时合成 6 轨疗愈白噪音
- **核心功能**：
  1. 6 轨程序化音频引擎（细雨落窗 / 深夜海浪 / 壁炉柴火 / 夏夜虫鸣 / 宇宙深空 / 森林微风）
  2. 4 套一键场景预设 + 自定义混音配方 `localStorage` 持久化
  3. 全屏沉浸式 4-7-8 呼吸疗愈模式
  4. 15 / 30 / 60 分钟睡眠定时器（结束前 10 秒平滑淡出至 0 并暂停）
  5. 「今日声景明信片」Canvas 高清竖版海报生成（含声纹波形、日期、心情文案与真实公网二维码）
